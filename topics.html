CLUSTER ACCESS GUIDE

SSH 权限开放参考操作

配置 SSH 密钥和动态验证码后，可以通过终端安全访问本科生算力平台。请依次完成以下步骤。

01 配置 SSH 密钥 02 添加集群公钥 03 配置动态验证码 04 登录集群 大赛 Q&A
1

在自己的电脑上生成 SSH 密钥

Windows 用户打开 PowerShell 或 Git Bash；macOS、Linux 用户打开终端。将邮箱替换成自己的邮箱后运行：

ssh-keygen -t ed25519 -C "your_email@example.com"

系统会询问密钥保存位置和私钥密码（passphrase）。建议为私钥设置一个短密码，其余项目可按回车接受默认值。

妥善保管私钥：id_ed25519 是私钥，绝不能泄露；id_ed25519.pub 是公钥，需要添加到集群。

macOS 或 Linux 用户可以运行下面的命令查看并复制公钥全部内容：

cat ~/.ssh/id_ed25519.pub
2

将公钥添加到集群账户

在校园网环境下访问 本科生算力平台，使用现有密码登录并选择“登录集群”。

创建 SSH 配置目录并设置权限

mkdir -p ~/.ssh
chmod 700 ~/.ssh

-p 表示按需创建目录；目录已存在时不会报错。

追加公钥并设置文件权限

echo "这里替换成您自己的公钥全部内容" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
复制 id_ed25519.pub 中的一整行内容，包括开头的 ssh-ed25519 和末尾的邮箱。命令中的两个大于号 >> 表示追加，不会覆盖已有密钥。
3

配置身份验证器与动态验证码

在手机上安装身份验证器应用，例如 Microsoft Authenticator、Google Authenticator、FreeOTP 或腾讯身份验证器。然后在集群命令行运行：

google-authenticator

终端会显示二维码、Secret Key 和 Emergency Scratch Codes。立即使用身份验证器扫描二维码，或手动输入密钥。

保存备用安全码：请将 Emergency Scratch Codes 离线保存在安全位置。手机丢失或应用不可用时可用其登录，每个备用码只能使用一次。

配置问题建议选择

  • 基于时间生成令牌（time-based）：y
  • 更新配置文件：y
  • 禁止同一令牌多次使用：y
  • 放宽时间容错范围：n
  • 限制尝试次数：y
4

通过 SSH 登录集群

完成配置后，在本机终端使用域名或 IP 地址连接。默认端口为 22：

ssh 用户名@107.ustc.edu.cn
# 或
ssh 用户名@114.214.255.132

用户名可在网页端集群信息中查看，通常是小写学号。登录时系统会要求输入私钥密码和手机身份验证器显示的 6 位动态验证码。
